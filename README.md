# TestProject

A project to test and help develope RetroFuturaGUI.

Check out the repository recursively and run cmake from the build directory with the following command:

```& "C:\Program Files\CMake\bin\cmake.exe" .. CMakeLists.txt -DTARGETPLATFORM=x64-windows -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake"```
